NQ Context.

A pair of custom indicators I built and trade live every morning on NQ futures. They take all the context I want on screen — gamma levels, value area, day type, volume profile, sweep state — and score the setup so I know when to act.

A live setup on NQ — gamma walls, confluence zone, day-type badge, setup score, and a fired sweep-reclaim trigger.

Why I built it.

Trading NQ in the cash open is information-dense. There are gamma walls from SpotGamma, value areas from the prior day's profile, round numbers, the initial balance, VWAP, day-type context — and you need all of it on screen in a glance to make good decisions.

Off-the-shelf indicators showed me one piece at a time. I wrote NQ Context to stack all the layers, detect when they line up, and tell me which side of the tape has the edge.

What it does.

  • Gamma levels. 0DTE, weekly, and monthly call walls, put walls, and gamma flip lines — each with timeframe-specific styling. Includes a staleness tracker so I know when the data is too old to trust.
  • Confluence zones. Auto-detects price areas where prior-day POC/VAH/VAL stack with round 100s/50s and key QQQ-equivalent levels using a live NQ/QQQ ratio.
  • Session volume profile. POC/VAH/VAL drawn in real time over the day's range, with a side histogram showing where volume actually transacted.
  • Day type detection. Measures the Initial Balance against daily ATR and classifies the day — Trend Day, Balanced, Wide IB Range, Coiling, Double Distribution, etc.
  • Sweep tracking. Flags when price wicks through VAH/VAL/PDH/PDL/IBH/IBL, then watches for a reclaim back inside the level.
  • Six trigger patterns. Sweep + Reclaim, Rejection Wick at Level, Trend Pullback to VWAP, Failed Breakout, Volume Climax Reversal, and Compression Break.
  • Setup scoring. Combines every context layer into a 0–10 confidence score. Triggers only fire when the score crosses a threshold, which keeps me out of forced trades.
  • CVD divergence. Companion script tracking cumulative volume delta against price pivots, auto-flagging bull/bear divergences as they form.

The setup score.

At the heart of the script is the scoring logic — it stacks every layer of context into a single number, so I can judge if a setup is worth taking in a glance.

nq_context.pine Pine v6 
1// Score a long setup by stacking layers of confluence
2longScore = 0
3if inZone
4    longScore := longScore + 2          // +zone
5if aboveFlip and primaryFlip > 0
6    longScore := longScore + 2          // +flip
7if not na(curVAL) and
8     math.abs(close - curVAL) <= levelProx
9    longScore := longScore + 1          // +VAL
10if nearestPW > 0
11    longScore := longScore + 1          // +put wall
12if close > vwapVal
13    longScore := longScore + 1          // +VWAP
14if longSweep or longWick or longPullback
15    longScore := longScore + 1          // +trigger
16
17// Only fire when conviction is high enough
18fireLong = longScore >= minScoreFire
19if fireLong
20    alert("NQ Ctx: LONG · Score " + str.tostring(longScore))

A pristine setup — sitting in a confluence zone, on the right side of the gamma flip, near value, with a trigger firing — hits 8/10 and the alert fires. Mediocre setups (3–5/10) stay quiet so I don't take them.

How I use it.

Every morning before the open I plug in fresh gamma levels from SpotGamma. The script does the rest: draws every level, watches for sweeps, scores setups in real time, and pings my phone when a high-conviction trigger fires.

Still iterating. It's the kind of project that will never be "done" — every trade teaches me something to add or refine.
